# R4 独立对象层

## 分层

- `World` / Chunk / `BlockId`：1 m 地形体素，负责挖掘、填充和地形 Mesh。
- `ObjectStore`：静态独立对象的权威状态，负责稳定 ID、类型、锚点、四向旋转、占地与净空。
- ECS Entity：可丢弃、可重建的视觉表现，不得写入存档身份。
- GLB：由稳定对象类型映射到 R3.1 已锁定的稳定素材 ID；GLB 路径和 glTF 节点索引不是存档语义。

## 初始对象类型

| 类型 ID | R3 素材 ID | 占地 | 净空 |
|---|---|---:|---:|
| `campfire_basic` | `bonefire` | 3×3 | 1 m |
| `tent_basic` | `tent` | 4×3（旋转后 3×4） | 3 m |
| `stone_pile_small` | `stone_03` | 4×4 | 1 m |

这是 R4 的参考目录，不是最终完整内容表。后续对象类型可以扩展，但已有类型 ID 和持久化含义不得静默重用。

## 放置规则

1. 锚点为对象占用体积的最小 X/Y/Z 体素坐标；Y 是支撑地面上方第一格。
2. 全部 footprint 下方必须是实体地形，并位于同一 Y 平面。
3. 全部净空体素必须为空气，且不得使用世界顶层 `H-1` 安全空气层。
4. 对象占用体积不得与其它对象重叠。
5. 地形编辑不得在对象占用体积内放置实体，也不得移除对象的支撑体素。
6. 四向旋转只改变 90° 离散方向和旋转后的占地，不保存任意浮点欧拉角。

## 交互

- `1/2/3`：选择对象类型。
- `G`：旋转 90°。
- `P`：在当前地形命中面外侧尝试放置；移动模式下提交新位置。
- `O`：选择光标下最近对象。
- `M`：移动已选对象。
- `X`：删除已选对象。
- `Esc`：取消移动。
- `F5`：对象预写 + 地形提交，形成可恢复的伴随保存。

## 当前边界

R4 只做静态对象。没有库存、生产、动画状态、居民、导航占用更新、建筑结构、对象堆叠或对象流送。完整建筑素材仍只是对象原型，不替代后续模块化建筑构件。
